# Student Performance Data Analysis 📊

## 📌 Project Overview

This project focuses on analyzing student performance data using Python and its data analysis libraries. The main objective is to explore student academic performance, identify patterns, understand relationships between different variables, and generate meaningful insights through data analysis and visualization.

The project covers complete Exploratory Data Analysis (EDA), including Univariate, Bivariate, and Multivariate Analysis.

## 🎯 Objectives

- Understand the structure and characteristics of the dataset.
- Perform data cleaning and preprocessing.
- Analyze individual variables and their distributions.
- Identify relationships between different variables.
- Explore factors associated with student academic performance.
- Create meaningful visualizations.
- Generate insights and prepare a data analysis report.

## 🛠️ Technologies & Libraries Used

- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical data visualization
- **Google Colab** – Development environment

## 📂 Dataset Information

The dataset contains student-related information and academic performance details.

- Total Records: 260
- Total Columns: 12

### Important Features

| Column | Description |
|---|---|
| stud_id | Student ID |
| pass_final | Final pass status |
| parental_education | Parent's education level |
| extracurricular | Extracurricular participation |
| math_score | Mathematics score |
| reading_score | Reading score |
| writing_score | Writing score |
| attendance_pct | Attendance percentage |
| study_hours_per_week | Weekly study hours |

## 🔍 Analysis Performed

### 1. Data Cleaning
- Checked missing values.
- Checked duplicate records.
- Examined data types.
- Generated statistical summaries.
- Investigated duplicate or redundant columns.

### 2. Univariate Analysis
Analyzed individual variables to understand their distributions and characteristics.

Techniques used:
- Histograms
- Box Plots
- Count Plots
- Distribution Analysis

### 3. Bivariate Analysis
Analyzed relationships between two variables to identify patterns and associations.

Techniques used:
- Scatter Plots
- Correlation Analysis
- Correlation Heatmaps
- Box Plots
- Cross Tabulation

### 4. Multivariate Analysis
Analyzed three or more variables together to understand complex relationships and patterns.

Techniques used:
- Pair Plots
- Multivariate Correlation Heatmaps
- Scatter Plots with Hue and Size
- GroupBy with Multiple Columns
- Pivot Tables
- 3D Scatter Plots

## 📊 Key Insights

The analysis explores:

- Relationships between study hours and academic scores.
- The association between attendance and student performance.
- Relationships among mathematics, reading, and writing scores.
- Differences in academic scores across parental education groups.
- Academic performance patterns based on extracurricular participation.

## 🚀 How to Run This Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Sirishak348/Student-Performance-Data-Analysis.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Student-Performance-Data-Analysis
   ```

3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Open the Jupyter Notebook or upload it to Google Colab.

5. Run the cells to explore the complete analysis.
